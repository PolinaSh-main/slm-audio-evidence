## Стадия A (19–29.07)

1. **A0 · DataSphere (19–20.07).** Адаптировать `notebooks/colab_run.ipynb` под DataSphere (доступ выдаёт M1). Smoke-тест: 5 элементов пилота через Qwen2-Audio. *Готово, когда:* один полный прогон воспроизводится на DataSphere.
2. **A1 · Скейл-сет на нативном SQuAD 2.0 (20–23.07).** Масштабируемся в своём домене: SQuAD 2.0 содержит ~6 тыс. написанных людьми безответных вопросов **к тем же параграфам**, которые уже есть в твоём пуле `data.csv`.
   - **NMSQA-разведка (~1 ч, пн 20.07):** скачай метаданные [voidful/NMSQA](https://huggingface.co/datasets/voidful/NMSQA) — его *test* — те же SQuAD-параграфы, начитанные 60 живыми дикторами. Пересеки test-параграфы с безответными SQuAD 2.0 dev и доложи M1 числа: сколько C и A ложится на натуральное аудио.
   - **Скрипт `data/make_scale_manifest.py` (20–21.07):** скачай dev-v2.0.json → нормализуй контексты → join с `data.csv` (чистые SQuAD-контексты там уже есть) → сэмпл ~200 C (`is_impossible=true`, `gold_answer: "UNANSWERABLE"`) + ~200 A (ответ = `answers[0].text`) по разным пассажам → манифест по PLAN §2: `generator: "native-squad2"`, у C `subtype: "native-unanswerable"`, `source: "spoken-squad"` или `"nmsqa"`. Если натуральных C ≥ ~100 — делай сет двухчастным (например ~200 TTS + ~150 natural). Спот-чек 30 строк: аудио соответствует параграфу. Состав утверждает M1 (Решение 1, пн–вт).
   - **Прогоны (21–23.07):** обе системы (Qwen2-Audio, каскад) × {plain, S1} на скейл-сете. Ответы — M4 на оценку.
   - *Готово, когда:* манифест в `data/manifests/`, 4 прогона в `results/`, файлы у M4. Обёртки, харнесс и судья не меняются.
3. **A2 · Вычислительные прогоны в помощь M1 (22–29.07).** Стержень A2 (дизайн, зонды, анализ) целиком ведёт M1; твоя часть — вычисления на DataSphere:
   - **Снятие представлений (22–23.07):** прогнать код снятия от M1 по пилоту-100 (+ элементы скейл-сета), тензоры → `results/probing/` **к 23.07**.
   - **Сэмплирование (23–24.07):** k≈10 ответов на элемент (temperature > 0 — переиспользуй поле `samples` харнесса); файлы — M4 на оценку **к 24.07**. От этих двух дедлайнов зависит чекпоинт пт 24.07.
   - **По запросу M1 (25–29.07):** прогоны и отладка attention-зонда и митигационных замеров.
   - Страховка: если M1 недоступен — линейные зонды обучаешь сама по его спеке.
   - *Готово, когда:* тензоры (23.07) и сэмплы (24.07) доставлены; запросы M1 закрыты.
4. **Стоп ср 29.07** — заморозить все файлы результатов; новых прогонов после этого нет.
